# TractorCompare AI v22.3 candidate — full specification audit

Date: 2026-11-15

## Why this update exists
The v22.2 queue diagnostic confirmed that the Gemini interaction completed and generated 43 specifications, but its default diagnostic intentionally returned only the first 8 preview entries. Before finalizing the run, the remaining specifications must be checked for exact source URL and evidence.

## Changes
- Extends the queue-secret protected, read-only `diagnose_queue_run` action.
- Optional request field `include_full_spec_audit: true` returns up to 60 bounded specification audit rows.
- Each row includes index, spec name/value/unit, source_url, up to 1,200 characters of evidence, page number, measurement_standard, rated_rpm and confidence.
- The option does not mutate queue, run, documents or findings.
- All v22.2 functionality remains: strict Fendt 724 Vario Gen7.1 source allow-list for new runs, queue-to-run and tractor identity checks, and mandatory human review.

## Deploy
Deploy `indexim-v22.3.ts` as the Edge Function entrypoint. No SQL migration is required.
