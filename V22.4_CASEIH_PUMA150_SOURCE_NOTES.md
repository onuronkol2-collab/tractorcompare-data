# TractorCompare AI v22.4 candidate — Case IH Puma 150 official brochure

Date: 2026-11-15

## Root cause
The Case IH Puma 150 queue row had status `needs_source` because the previous attempt used the generic `https://www.caseih.com` homepage. The server-side crawler could not extract sufficient visible text from the JavaScript-rendered homepage, so the research run failed before any Gemini interaction or source document was created. The subsequent 409 was expected because the claim RPC intentionally accepts only queued/retry or stale running jobs, not needs_source.
