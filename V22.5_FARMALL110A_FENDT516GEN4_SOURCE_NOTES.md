# TractorCompare AI v22.5 — Farmall 110A + Fendt 516 Gen4

Date: 2026-11-15

## Scope

This candidate is based on v22.4 and preserves its Case IH Puma 150 official-brochure fallback, Fendt 724 Vario Gen7.1 source lock, queue diagnostics, full specification audit, and human-review-only behavior.

### Case IH Farmall 110A

- Official product page: https://www.caseih.com/en-gb/europe/products/tractors/farmall-series/farmall-90-110-a
- Exact official brochure linked from that page:
  https://cnhi-p-001-delivery.sitecorecontenthub.cloud/api/public/content/f07d27f3f2ff43caa2b582f82d53ceba?v=aa4634ce
- Printed page 3 contains the separate FARMALL 110 A row. The prompt explicitly excludes adjacent 100 A and 90 A rows.
- The PDF is marked for worldwide circulation; availability/equipment can vary by country. No model year is stated.
- The delivery hostname is an existing narrow Case IH first-party asset-host allowlist entry.

### Fendt 516 Vario

- Exact technical-data endpoint:
  https://api.fendt.com/techdata/GB/en/1520018/Fendt-500-Vario-Gen4
- The candidate accepts exactly this Gen4 endpoint for the requested 516 Vario model and requires HTTP 200 plus exact model evidence.
- The prompt restricts extraction to the dedicated 516 Vario column and records Fendt 500 Vario Gen4, source locale GB, and unspecified model year.
- It deliberately excludes prior 500 Vario / Gen3 data. In particular, the older data table lists 4,038 cm3, 163 hp, and ML 90 while Gen4 lists 5,017 cm3, 164 hp, and TA120 VarioDrive. These generations must not be merged.
- Findings remain pending human review; the tractor record's generation/year is not automatically changed.

## Safety and compatibility

- No SQL migration is required.
- No historical runs, source documents, findings, or tractor specifications are deleted or overwritten.
- AUTO_APPROVE_VERIFIED_FINDINGS remains false.
- Existing Fendt 724 and Case IH Puma 150 source rules are retained.
- This is a candidate branch only. It is not deployed to Supabase.

## Deployment

Deploy the complete indexim-v22.5.ts source as the existing TractorCompare AI Edge Function. Do not deploy until reviewed in Supabase's normal deployment workflow.

After deployment, requeue only the two failed source-discovery queue rows using the guarded SQL supplied with the handoff. Keep their attempt counters and historical failed runs intact. Then run process_queue_for_tractors for Farmall 110A, Fendt 516 Vario, and Deutz-Fahr 6165 together; the Deutz request will poll and finalize its already-completed Gemini interaction rather than creating a new interaction.
