A sitemap, hreflang or self-canonical alone does not establish navigable internal discovery. Google guidance: https://developers.google.com/search/docs/crawling-indexing/links-crawlable . The existing targeted catalogue discovery checks remain in place.

Reuse each already-fetched page (no extra HTTP requests, paid API, JS execution or crawling of arbitrary links). The new graph counts only same-origin, exact listed canonical URLs from real non-nofollow HTML anchors; ignores scripts, comments, raw text, inert templates, self-links, query-only variants, redirect aliases and external URLs. Fragment destinations on other pages count as links to their base canonical. Report distinct source-target edges, all locale entry roots, pages with no verified incoming canonical anchors and unreachable clusters separately. This is a conservative candidate inventory, not proof of actual Google crawling/indexing; a legitimate redirect alias, dynamic navigation or nofollow link may not count. A future base href prevents a complete claim. In partial mode, negative graph conclusions are null, not zero.

Full candidate URL arrays are preserved in the existing audit JSON artifact. Existing error/title warning counts remain comparable.
