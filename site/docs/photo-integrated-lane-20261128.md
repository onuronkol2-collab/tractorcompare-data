# Photo research integration, 28 November 2026

The trusted-main research workflow starts in explicit manual modes. `bootstrap` initializes an empty public checkpoint only when no existing checkpoint exists, applies a conservative 24-hour Commons pause, and does not call image providers. `restore` restores and verifies the latest checkpoint and seals a successor without provider requests. Only after both succeed should daily research be re-enabled in a protected change. `research` runs the existing Commons discovery, Openverse and independent Finna/LOC public metadata lanes with current coverage and a shared Commons budget. The recorded 429 pause is applied before any provider request.

Public Actions artifacts contain only allowlisted public research reports and minimal public checkpoint state. Raw private collector snapshots, original image bytes, source-rights decisions, private hold ledger, credentials and final image review are not uploaded to Actions. Acquisition and OCR tools are local/trusted-worker only until private authenticated storage, quota and restore are independently verified. No automatic rights or identity approval; no image publishing occurs in this workflow. The public checkpoint retention limit is 90 days, not a permanent private archive. Do not reset an expired or corrupt checkpoint silently.
