## Search and publishing gate

The photo research code may use aliases **only to discover candidate file pages**; it never publishes an image. File identity requires three independent signs (badge/trim/photo source/body geometry) and year/market fit. Permissions require file-level original URL, photographer, license, license URL, attribution, verification date and derivative allowances (exclude NC, ND). Every accepted image must be self-hosted, optimized, properly credited and have natural 10-language alt text. If either model or license remains uncertain, keep the empty state with an explicit honest message.

### More evidence needed for next pass

1. Wikimedia Commons file-page identity and CC BY / BY-SA / CC0 / public-domain license where the model and trim match.
2. If none, a *written* commercial web publication and cropping/optimization permission from manufacturer, distributor or photographer. Never infer permissions from marketing pages, dealer listings, search images or supplier PDFs.
3. After evidence, add one model photo through the existing allowlisted image pipeline and run the image SEO/live JPEG/attribution tests. Do not bulk-publish draft tractors.
