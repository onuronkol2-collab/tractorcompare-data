- Japan: NARO original Japanese inspection list for exact domestic model and safety equipment, then regional Kubota/Iseki/Yanmar OEM catalogue. A safety approval is not a performance test. Korea KoAT, China ministry and other national bodies supplement discovery only until real model-specific documents are available.
- Historical machines: UNL, Iowa State, Wisconsin, Wageningen, Ventura and INRAE. Use original publication dates, no copy of entire brochures, item rights. Historical research is separate from the user's 2026-only reliability/failure article rule.

Manufacturer press media requires explicit reusable licence. Do not republish photos in a test report by default.

## Retention and use
Maintain the directory with checked date, actual public URL, evidence class, scope, and rights. A new source must never be treated as trustworthy for every claim by hostname alone. No network calls are triggered by this JSON. Current confirmed source URLs come from institutional search results, not full item-by-item document verification. On each request use actual private catalogue gap counts, source-linked candidate and hash history, bounded free collection, independent review, guarded writes, batch CI and real production validation. A blocked source does not block independent sources; honor provider limits. Record candidate vs published vs live counts separately, never assume photo rights or claim availability of a particular report not accessed.
