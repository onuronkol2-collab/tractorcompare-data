# Independent evidence and photo fallback — 2026-11-24

Technical facts, independent observations and photo assets are separate work lanes. Never interpret an inaccessible optional source or missing photo as a mandatory technical publication failure. Never treat the routing helper as publication permission. Preserve the existing catalogue readiness, genuine independent review where required, minimum verified content, RLS, SEO/GEO, locale, release and rollback gates.

## Alternative source ladder
1. Search original OEM model page, same market manual, catalogue and serial/variant-specific technical sheet; compare actual model columns and units. Same-origin translations or dealer copies of OEM sheets are corroboration of transcription, not independent evidence. Record exact URL, date, page/table, scope, uncertainty, and actual document hash when bytes are available. Do not invent hash or model year.
2. For independent measurements search OECD, Nebraska, DLG, national institutes, universities, peer-reviewed papers and field trials in local language; distinguish equipment, field conditions, observation date, sample, market, measurement point and independent provenance. Do not require an independent measurement for a clearly labelled OEM nominal specification unless existing release gate explicitly requires it. Never replace genuine independent review with the assistant's own approval. Reliability/failure claims retain the 2026-only observation rule. Do not infer breakdown incidence from a field trial.
3. When provider is blocked, respect Retry-After/robots/access conditions; use alternative lawful origin or a truly independent archive, not a proxy to circumvent the restriction. Only hold affected facts; check remaining verified coverage. If core identity or mandatory gate remains unresolved, keep draft.
4. Photo optional for technical page: use existing no-photo state, no false ImageObject, no mislabeled substitute, no synthetic machine image as real photo. Separate worklist searches Commons grouped by brand, Openverse/Flickr/Europeana, public-domain archives and explicit OEM reuse permission. Check rights, attribution, identity, exact original bytes, hash, image decode, MIME, derivative permission, first-party serving and live photo tests before photo approval. Do not relax the site photo source allowlist or use an unverified remote image.
5. Before actual publication, use existing release process; verify public view, HTML, locale/canonical/hreflang/sitemap, SEO metadata and actual deployment. If a photo is absent, verify its absence does not emit fabricated photo metadata. Test failures are solved or isolated only if the required gate genuinely excludes the independent item. Keep private draft worklists outside public repo/artifacts.

## Batch review

Run `node scripts/tractor-catalogue-batch-review.mjs < private-candidates.json` locally. Supply a JSON array of the existing `routeCatalogueEvidence` inputs with observed gate results. The output groups zero-based input positions into automated nominal release candidates, existing release-review candidates, candidates waiting only for required special review, and held models. Photo queues and held claim keys are independent. Each malformed record is identified by position. A malformed top-level input exits with an error. Keep input and output private. The command performs no network requests or writes. For nominal specifications use the owner-approved automated evidence decision described in [the current nominal release protocol](tractor-automated-nominal-release-20261125.md); apply actual reviewer decisions per record only when a special independent or human review is genuinely required. Use the existing publication and public-site sync. Verify the changed field or image on the live URL.

## Offline regression guard
`scripts/tractor-split-evidence-review.mjs` exports a pure routing helper. The caller supplies observed gate statuses only, never synthesizes pass. It cannot fetch, write, publish, accept a photo, or replace the existing gates. Use its routes to prioritize safe review or research. `site/tests/tractor-split-evidence-review.test.mjs` tests missing photos, OEM-only nominal evidence, independent-evidence requirements, 2026 scope, claim isolation, all mandatory gates and malformed inputs. This pilot is not a release approval or evidence that live records were updated.
